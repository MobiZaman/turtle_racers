## Turtle Racing Game

A simple Python-based turtle racing game where multiple turtles compete on a track, and a random winner is declared based on movement speed.

## Features

- Animated turtle racing simulation with smooth movement  
- Multiple turtles racing simultaneously with different colors  
- Randomized movement for each racer to create unpredictable outcomes  
- Clean race track with clearly marked start and finish lines  
- Automatic winner detection based on race progress  
- Keyboard control to restart the game easily  
- Simple and beginner-friendly Python project demonstrating game logic and animation  

## How to Run

1. Install Python 3
2. Download or clone this repo
3. Run: **python main.py**
